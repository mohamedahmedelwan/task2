CSS عنوان التقرير


المقدمة

تُعد لغة CSS (اختصار Cascading Style Sheets أي «أوراق الأنماط المتتالية») إحدى التقنيات الأساسية الثلاث لصفحات الويب، إلى جانب HTML وJavaScript. فبينما تحدد HTML محتوى الصفحة وهيكلها من عناوين وفقرات وصور، تتولى CSS تحديد الشكل الذي تظهر به هذه العناصر أمام المستخدم، من ألوان وخطوط ومسافات وطريقة ترتيب.

اقترح هوكون فييوم لي فكرة CSS عام 1994، وصدر أول إصدار رسمي منها (CSS1) كتوصية من منظمة W3C في ديسمبر 1996، ولا تزال المنظمة مسؤولة عن تطوير مواصفاتها حتى اليوم. وتكمن أهميتها في أنها تفصل المحتوى عن التصميم؛ إذ تُكتب قواعد التنسيق مرة واحدة في ملف مستقل وتُطبق على عدد كبير من الصفحات، مما يوفر الوقت ويجعل الموقع متناسقًا وسهل التعديل وجذابًا على مختلف الأجهزة.

عرض الموضوع

  1. بنية قاعدة CSS

    بدون CSS تظهر الصفحة نصًا أسود على خلفية بيضاء، وبها يمكن تغيير الألوان والخطوط والمسافات وترتيب العناصر. وتتكون القاعدة من:

    • المحدد (Selector): يحدد العنصر المراد تنسيقه.
    • الخاصية (Property): ما نريد تغييره.
    • القيمة (Value): القيمة الجديدة للخاصية.

    في المثال التالي تجعل القاعدة كل عناوين h1 بلون أزرق وبحجم خط 32 بكسل:

    h1 {
    color: #1a5fb4;
    font-size: 32px;
    }

  2. طرق ربط CSS بصفحة HTML

    هناك ثلاث طرق:

    • الخارجية: ملف css. منفصل، وهي الأفضل لأنها تخدم صفحات كثيرة.
    • الداخلية: وسم style في رأس الصفحة.
    • المضمّنة: خاصية style على عنصر واحد.

    <link rel="stylesheet" href="styles.css"> (External)
    <style> p { color: gray; } </style> (Internal)
    <h1 style="color: red;">Hello</h1> (Inline)

  3. المحددات والألوان والخطوط

    تسمح المحددات باختيار العناصر بحسب:

    • الوسم مثل p
    • الفئة (class) وتبدأ بنقطة
    • المعرف (id) ويبدأ بعلامة #

    ويمكن تحديد اللون بالاسم أو بالرمز السداسي #1a5fb4 أو بالدالة rgb()، ويُختار الخط بالخاصية font-family مع خط بديل احتياطي:

    .card { background-color: #f4f6f8; } /* class */
    #title { text-align: center; } /* id */
    body { font-family: Arial, sans-serif; color: #222222; }

  4. نموذج الصندوق (Box Model)

    يُعامل كل عنصر كصندوق من أربع طبقات من الداخل إلى الخارج:

    1. المحتوى
    2. الحشو الداخلي padding
    3. الحد border
    4. الهامش الخارجي margin

    وبشكل افتراضي يطبق العرض width على المحتوى فقط، أما box-sizing: border-box فتجعله يشمل الحشو والحد أيضًا:

    .box {
    width: 300px;
    padding: 20px;
    border: 2px solid #1a5fb4;
    margin: 10px;
    box-sizing: border-box;
    }

  5. لمسات الجمال: التأثيرات عند التفاعل

    تضيف CSS حيوية للصفحة عبر الفئة الشبيهة hover: التي تُطبق التنسيق عند مرور الفأرة، مع transition لجعل التغيير سلسًا:

    .button { background-color: #1a5fb4; color: white; border-radius: 8px; transition: background-color 0.3s; }
    .button:hover { background-color: #0b3d80; }

  6. التصميم المتجاوب مع الشاشات

    يهدف إلى ظهور الصفحة بشكل جيد على الهاتف والحاسوب، ويعتمد على:

    • استعلامات الوسائط (Media Queries): تطبق تنسيقات عند تحقق شرط كعرض الشاشة.
    • Flexbox: للترتيب في اتجاه واحد.
    • Grid: للترتيب في بعدين.

    المثال التالي يرتب العناصر بجانب بعضها عندما يبلغ عرض الشاشة 600 بكسل أو أكثر:

    @media screen and (width >= 600px) {
    .wrapper { display: flex; } }
